# AWS EC2 Static Website Deployment

##  Project Overview
This project demonstrates how to deploy a static website on an AWS EC2 instance using Nginx web server.

##  Technologies Used
- AWS EC2
- Linux (Ubuntu)
- Nginx Web Server
- HTML

##  Steps Performed
- Created EC2 instance on AWS
- Connected via SSH
- Installed Nginx server
- Configured security groups (HTTP & SSH)
- Deployed custom HTML page
- Accessed website via public IP

##  Final Result
Website is hosted on AWS EC2 and accessible via public IP address.

##  Architecture
User → EC2 Instance → Nginx → index.html

##  Learning Outcome
- Cloud computing basics
- Linux server management
- Web server deployment
- AWS EC2 fundamentals
